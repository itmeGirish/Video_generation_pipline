# Step 6b — Critique and Improve

The content gate (rule 06) tells you PASS/FAIL. This step does the harder work: it
**critiques the script the way a world-class YouTube writer would, then rewrites or
rebuilds the weak parts.** A pass score is the floor, not the goal — this pushes the
script toward the quality of the top channels in the niche.

## Be the world-class reviewer

Review this script as if you are a top-tier YouTube scriptwriter — the kind who writes
for channels with millions of subscribers — brought in to critique a draft before it
ships. You've studied what the best channels do (cold opens, curiosity chains, tight
pacing, a real voice, payoffs that land), and you hold this script to that bar.

See it from EVERY angle at once:
- **The scroller** deciding in 2 seconds whether to click away
- **The skeptic** in the comments hunting for a wrong fact or a weak claim
- **The fan** who came for insight and will share it if it's good
- **The editor** who knows which scene is dead weight
- **The competitor** whose video on this topic is one click away

Then ask the question the best writers ask: *"Would this make it onto a top channel as-is?
If not, exactly what's holding it back?"* Don't praise it. Find what's wrong, verify the
facts, and lift it to that standard.

Two hats, in order: **master reviewer first, then editor.**

## How to run it — critique, then improve, then re-check

1. **Critique (reviewer hat):** read the whole script and attack it against every check
   below. Write the honest, specific weakness for each — not "fine," but what's wrong
   and where. Be the harshest reasonable reviewer.
2. **Improve (editor hat):** rewrite only the weak parts the critique found. Keep what
   works. Route each weakness to the rule that owns the fix.
3. **Re-check:** re-run rule 06 (content gate) and rule 05b (human review). If anything
   still fails, loop. Stop only when the critique can't find a real weakness left.

Do not skip step 1. A script you didn't genuinely try to break is a script you haven't
reviewed — you've only admired it.

---

## The quality score — and the rebuild threshold

After the critique, score the script so the right action is obvious: **patch a good
script, but REBUILD a weak one.** Patching a fundamentally weak script just polishes a
bad idea.

Score each of the content checks PASS = 1, WEAK = 0.5, FAIL = 0, across rule 06's tests
and rule 05b's questions. Quality factor = (points earned) / (total checks).

| Quality factor | Meaning | Action |
|---|---|---|
| **≥ 0.85** | Strong | Patch — improve the few weak parts (improve loop) |
| **0.6 – 0.85** | Mixed | Patch hard — rewrite every weak scene, re-critique, loop |
| **< 0.6** | Weak at the core | REBUILD — the foundation is wrong; build a new script (rebuild loop) |
| **Any hard FAIL on hook, value, or thesis** | Broken foundation | REBUILD regardless of score — these can't be patched in |

The factor is a decision aid, not a grade to optimize. A 0.84 with a dead hook still
rebuilds; the hook/value/thesis FAILs override the number. Below 0.6, or with a broken
foundation, stop patching and rebuild.

## Fact-accuracy check (every claim must be true)

A top channel lives or dies on credibility. One wrong fact in the comments and the video
is "that one with the error." Fact accuracy is non-negotiable and a hard gate — a script
with an unverified or wrong fact does NOT pass, regardless of how good it reads.

Go through the script claim by claim:
- **Every number, stat, date, name, and quote is verified against a real source** (rule
  00 research). If a figure has no source, it is unverified → flag it.
- **Nothing is hallucinated** — no invented benchmark, fabricated quote, made-up study,
  or "sounds right" number. If you can't point to where it came from, it doesn't ship.
- **Nothing is stale** — a figure that was true once but has since changed is now wrong.
  Re-check anything time-sensitive (rule 06 Test 7).
- **Claims match their evidence** — the script doesn't overstate what the source says
  ("a study suggests" became "studies prove"), and correlation isn't sold as causation.
- **Names and attributions are correct** — the right person said the quote, the right
  company shipped the thing, the spelling is right.

For anything you cannot verify from the existing research, run a quick check (rule 00 /
WebSearch) or cut the claim. When sources conflict, present the uncertainty, don't pick
silently.

**PASS:** every fact is verified and correctly stated; sources exist for each number.
**FAIL (hard):** any unverified, fabricated, stale, or overstated claim — fix or cut
before anything else. A factually wrong script cannot be "improved" into a good one.

## The critique checklist (all rules + top-channel bar)

For each line, write the specific weakness (with scene/line) or "holds up — why."

**Content quality (rule 06):**
- Hook — is Scene 1 actually compelling, or just "fine"? Where would a viewer NOT stop?
- Unique angle — what does this say that the top videos don't? If nothing, say so.
- Value — finish the sentence "a viewer can now ___." Is it specific and real?
- Evidence — which claim is least supported? Which number lacks a source?
- Tension/resolution — is the hook actually paid off, or quietly dropped?
- "So what" — which scene could be cut with no loss?
- Freshness — what's stale, dated, or superseded?
- Human-not-AI — where does it read generated? Quote the filler / banned words (rule 02 list).
- Specificity — which lines are vague ("a lot," "many," "significant")? Each needs a real number/name.
- Not generic — could this be find-and-replaced to another topic? Which lines survive the swap?
- Not over-polished — where is it sterile, corporate, voiceless?
- Psychology — is there a real curiosity gap, anticipation, emotion, a reason to share?

**Human viewer review (rule 05b):**
- Robotic + tone — does it sound like a person? Is the tone consistent and right?
- Understand — where would a non-expert get lost?
- Keep-watching — which scene is the most likely drop-off point?
- Why-watch / what they GET — would they feel it was worth their time?
- Makes them think/feel — is there a single moment they'd react to or share?
- Makes sense — can you summarize the whole thing in one sentence?
- Continuity — do scenes link, or does attention reset at the cuts?

**Storytelling (rule 01b):**
- Story not list — does it feel like a story (stakes, build, payoff) or facts read out?
- Cause-and-effect — do scenes connect by "because of that," or just "and then"?
- Stakes & transformation — is there a reason to care and a before→after that lands?

**Fact accuracy (hard gate — see section above):**
- Is every number, name, date, and quote verified against a real source?
- Is anything hallucinated, stale, or overstated beyond what the source says?

**The top-channel bar:**
- Would this make it onto a top channel in this niche as-is? If not, what's the gap?
- Compared to the best video on this topic, where is this weaker — and how do we beat it?

**The killer questions (answer all, bluntly):**
- What is the single weakest scene, and exactly why?
- Which one claim would a skeptic in the comments tear apart (or fact-check and disprove)?
- If this got views but zero shares, what's the most likely reason?
- What's the one change that would most improve this script?

## How to improve — route each weakness to its fix

Every weakness the critique found maps to a specific fix and the rule that owns it:

| Weakness found | Fix | Owning rule |
|---|---|---|
| Unverified / wrong / stale fact | verify and correct, or cut the claim | 00 |
| Reads as a list, not a story | add a spine, stakes, cause-and-effect, transformation | 01b |
| Weak hook | rewrite Scene 1 to confirm the promise cold | 01 / 07 |
| Generic / no angle | sharpen the thesis, bring in specific researched facts | 07 / 00 |
| No real value | add a concrete takeaway and deliver it in the verdict | 01 |
| Unsupported claim | source it, or cut it, or pivot to a quote | 00 |
| Dropped hook | make the final scene answer Scene 1 | 01 |
| Cuttable scene | cut it, or give it a job | 01 |
| Stale facts | re-search, refresh figures | 00 |
| AI/robotic voice | rewrite spoken; strip filler vocabulary | 02 |
| Sterile/over-polished | loosen voice, add an honest opinion/aside | 02 |
| No curiosity/emotion | open a loop, add the high-arousal beat | 01 / 05a |
| Confusing | explain-then-reveal, one idea per scene | 01 |
| Drop-off scene | add a re-hook or cut it | 01 / 05a |

Rewrite the weak parts only. Don't rewrite scenes the critique found solid — that wastes
effort and risks breaking what works.

---

## The improve loop

```
1. Critique the script against the full checklist (reviewer hat)
2. List every weakness with scene/line + the one biggest improvement
3. Rewrite only the weak parts, routing each to its owning rule
4. Re-run rule 06 (content gate) and rule 05b (human review)
5. If a real weakness remains → go to 1
6. Stop when an honest critique finds nothing material left to fix
```

There is no fixed retry count. Keep going until the script is genuinely better, not just
technically passing. But stop polishing once the critique only turns up nitpicks — don't
over-polish past the point of value (rule 06 Test 10).

---

## The rebuild loop (low score → build a new script)

When the quality factor is **< 0.6**, or there's a hard FAIL on hook / value / thesis,
patching won't help — the foundation is wrong. Build a new script that self-improves
through critique. This is the same skill working on itself: critique → rebuild → critique.

```
1. Diagnose the root cause from the critique — WHY is it weak at the core?
   (no real angle? no value? wrong thesis? no evidence? boring topic framing?)
2. Go back to the foundation, not the prose:
   - Re-research if the facts/angle are thin (rule 00)
   - Re-pick the thesis and the unique angle (rule 07)
   - Re-plan scene structure and the loop chain (rule 01)
3. Write a NEW script from that stronger foundation (rules 02 / 03).
4. Run the content gate (rule 06) + human review (rule 05b) on the new script.
5. Critique the new script (this rule, from the top) and score it again.
6. If still < 0.6 → diagnose a DIFFERENT root cause and rebuild again.
   Do not rebuild the same way twice — each rebuild must change the foundation
   that the critique blamed, or it will fail the same way.
7. Stop when the score clears 0.85 and no hard foundation FAIL remains.
```

Each rebuild must fix the ROOT the critique identified — a new draft with the same weak
angle is not a rebuild, it's a retype. Track what the last critique blamed so the next
build doesn't repeat it. After the rebuild clears the threshold, finish with the normal
improve loop to polish the remaining weak parts.

```
CRITIQUE & IMPROVE — <name>
Quality factor: 0.78 — MIXED → patch hard

CRITIQUE (world-class reviewer, every angle):
  Fact check:      S2 stat unverified, S5 quote misattributed — both must be fixed
  Top-channel bar: hook is a tier below the best video on this topic
  Weakest scene:   S4 — the "so what" never lands; viewer would leave here
  Reads AI:        S3 — "it's important to note", uniform sentences
  No share reason: nothing here a viewer repeats to a colleague
  Biggest win:     give S4 a concrete takeaway and a payoff

IMPROVEMENTS MADE:
  S4 — added a decision rule the viewer can use; verdict now delivers it
  S2 — sourced the stat (rule 00); WARN cleared
  S3 — rewritten in spoken voice; filler removed
  S6 — planted one shareable reframe

RE-CHECK: rule 06 all PASS, rule 05b all PASS — factor 0.96
VERDICT: IMPROVED — ready
```

**Rebuild case (score < 0.6 or broken foundation):**
```
CRITIQUE & IMPROVE — <name>
Quality factor: 0.48 — WEAK AT THE CORE → REBUILD

ROOT CAUSE: no unique angle — it's a generic explainer; hook FAILs
REBUILD: re-research for a fresh angle (00) → new thesis (07) →
         new scene structure (01) → new draft (02/03)
RE-CRITIQUE of new draft: factor 0.88 — angle now specific, hook lands
VERDICT: REBUILT — ready (finished with a polish pass)
```

## Guidelines

### Always
- Review as a world-class YouTube writer holding the script to the top-channel bar
- See it from every angle: scroller, skeptic, fan, editor, competitor
- Fact-check every claim — verified sources only; a wrong fact is a hard FAIL
- Critique honestly first — attack the script before improving it
- Critique against every rule (06 content + 05b human review), not a favorite few
- Score the quality factor and let it decide: patch (≥0.6) vs rebuild (<0.6)
- Rebuild — don't patch — when the score is low or the hook/value/thesis is broken
- On a rebuild, fix the ROOT the critique blamed; never rebuild the same way twice
- Name the single biggest improvement and make it
- Rewrite only the weak parts; keep what works
- Re-run the gates after improving/rebuilding; loop until the score clears the threshold
- Route each fix to the rule that owns it

### Never
- Approve a script with an unverified, fabricated, or stale fact — accuracy is non-negotiable
- Hold the script to a lower bar than the top channels in the niche
- Skip the critique and jump to "looks good"
- Patch a script that's weak at the core — rebuild it instead
- Rebuild the same way twice — change the foundation the critique blamed
- Praise the script instead of stress-testing it
- Rewrite solid scenes and risk breaking what works
- Over-polish past the point of value (a sterile, voiceless script is also a fail)
- Approve while a real, named weakness is still unfixed
