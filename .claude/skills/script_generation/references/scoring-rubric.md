# Script Scoring Rubric — run before LOCK (verification-pass S7)

Score each dimension 1–5. **Ship at ≥4 average, with NO dimension at 2 or below.** A 2 anywhere blocks the
lock — fix and re-score. This is the consistency bar: the same rubric gates every script.

| Dimension | Test |
|---|---|
| **Hook strength** | Stake inside 5s? Open loop named? Zero forbidden openers (greeting/intro/title-restate)? |
| **Concreteness** | Example-before-abstraction in EVERY chapter? Running-example nouns ≥60% of sentences? |
| **Tension integrity** | Every tension released? Every open loop closed? Mid-video re-hook present (if >8 min)? |
| **Speakability** | Read the WHOLE script aloud once — zero stumbles, zero breath-starved sentences? |
| **Honesty** | Boundary chapter present? Hedges on volatile facts? Would the expert commenter be satisfied? |
| **Voice** | Sounds like the persona, not documentation? Banned-list clean? |
| **Clock-worthiness** | Every sentence one idea, one taggable concept, one animatable visual intent? |
| **Takeaway** | Can you say the one takeaway sentence from memory after one read? |

## Definition of Done (script) — the checklist before `locked: true`
- [ ] Topic Brief verdict GO with a named misconception.
- [ ] Every load-bearing fact primary-sourced + re-verified at lock (4 rounds logged).
- [ ] One running example, real numbers, ≥80% fact coverage, threaded through every chapter.
- [ ] Concrete precedes abstract in 100% of chapters.
- [ ] Hook: stake ≤5s, visual-lock intent, curiosity gap, promise — ≤30s, forbidden-opener clean.
- [ ] ≥1 open loop closed in the back half; mid-video re-hook if >8 min; pattern interrupt every 30–45s.
- [ ] Every sentence: one idea, ≤22 words, role-tagged, concept-tagged, visual-intent hinted (lint clean).
- [ ] Personality pass applied + diff-verified fact-safe; banned words zero.
- [ ] TTS-timed, pauses explicit, runtime within ±10% of budget, `locked: true`.
- [ ] Rubric ≥4 average, no dimension at 2.
- [ ] Blindfold test: the script alone, read aloud, is a complete and enjoyable explanation.
